📋 概述 / Overview

中文

PCAS Plugin（个人配置API搜题插件）致力于保护用户的隐私。本隐私政策说明了我们如何收集、使用和保护您的信息。

本插件不会收集任何个人身份信息，所有数据处理均在用户本地浏览器中完成。

English

PCAS Plugin (Personal Config API Search Plugin) is committed to protecting user privacy. This privacy policy explains how we collect, use, and protect your information.

This extension does not collect any personally identifiable information. All data processing is completed locally in the user's browser.

📊 数据收集 / Data Collection

中文

我们收集的数据：

  • 无 - 本插件不主动收集任何用户数据

网站内容访问：

  • 插件需要读取网页内容以识别题目文本
  • 此数据仅在当前会话中临时使用
  • 不会被存储、记录或上传到任何服务器
English

Data we collect:

  • None - This extension does not actively collect any user data

Website content access:

  • The extension needs to read web page content to identify question text
  • This data is only used temporarily during the current session
  • It is not stored, logged, or uploaded to any server

🔧 数据使用 / Data Usage

中文

本地存储的数据：

  • API配置 - 您配置的API地址和加密后的密钥
  • 查询历史 - 您的搜索记录（仅存储在本地）
  • 答案缓存 - 为提高性能而缓存的答案

这些数据的用途：

  • 仅用于提供插件的核心功能
  • 仅在您主动触发操作时发送到您配置的API
  • 不会用于广告、分析或任何其他目的
English

Data stored locally:

  • API Configuration - Your configured API address and encrypted key
  • Query History - Your search records (stored locally only)
  • Answer Cache - Cached answers for improved performance

Purpose of this data:

  • Used solely to provide the core functionality of the extension
  • Sent to your configured API only when you actively trigger an operation
  • Never used for advertising, analytics, or any other purpose

中文

具体说明：

Specifically:

🔒 数据安全 / Data Security

中文

安全措施：

  • API密钥使用WebCrypto API进行加密存储
  • 所有数据仅存储在用户的本地浏览器中
  • 不使用任何远程数据库或云存储
  • 不收集任何分析数据或遥测数据

我们采用行业标准的安全 practices 来保护您的数据，但由于数据仅存储在您的本地设备上，其安全性也取决于您设备的安全性。

English

Security measures:

  • API keys are encrypted using WebCrypto API
  • All data is stored only in the user's local browser
  • No remote databases or cloud storage are used
  • No analytics data or telemetry is collected

We employ industry-standard security practices to protect your data. However, since data is stored only on your local device, its security also depends on your device's security.

🌐 第三方服务 / Third-Party Services

中文

本插件不集成任何第三方服务。

插件的所有功能均在本地运行。唯一可能的外部连接是您自行配置的API端点，该连接：

  • 由您完全控制
  • 仅在您主动触发时连接
  • 不涉及任何第三方服务提供商
English

This extension does not integrate any third-party services.

All features of the extension run locally. The only possible external connection is the API endpoint you configured yourself, which:

  • Is fully under your control
  • Connects only when you actively trigger it
  • Does not involve any third-party service providers
